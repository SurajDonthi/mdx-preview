# Authoring documents

How to write documents for MDX Studio, and the parser rules you have to work within.

<Callout type="info" title="Read this in the app">
  Open this file with the Upload button to see the components below actually render.
  On GitHub the JSX shows as plain text.
</Callout>

---

## Read this first: it is not standard MDX

There is no `@mdx-js` in this project. `MdxRenderer.tsx` splits your document into
markdown chunks and JSX chunks with a hand-written character scanner, then compiles the
JSX chunks at runtime with `@babel/standalone` and evaluates them inside a
`React.Fragment` with a fixed set of names in scope.

Three consequences you cannot design around:

### 1. A document can only *use* components, never declare anything

Your document body becomes the inside of a fragment. There is nowhere to put a
statement, so this is impossible:

```jsx
const items = [1, 2, 3]        // ✗ not possible
function MyThing() { ... }     // ✗ not possible
const [n, setN] = useState(0)  // ✗ not possible
```

Anything stateful or computed has to live inside a component registered in
`src/components/CustomComponents.tsx`. Pass data to it as a prop instead:

```jsx
<FlowGraph data={{ nodes: [...], edges: [...] }} />   // ✓
```

### 2. Braces in prose will destroy your document

Inside a JSX chunk, `{` opens a JavaScript expression. This looks like text but is not:

```jsx
<Callout title="Note">
  Store documents under users/{uid}/documents/{id}.
</Callout>
```

<Callout type="error" title="This is the single most common way to break a document">
  A brace pair in JSX text compiles as a variable reference and throws. The entire
  document then silently falls back to plain markdown — every component stops rendering
  and all you get is a small Fallback View Active banner. It has happened twice while
  writing these very docs.
</Callout>

That compiles as a variable reference, throws `uid is not defined`, and takes the whole
document down with it.

Fixes, in order of preference:

- Rephrase to avoid braces: `under each user's uid record`
- Move the text out of the component into a normal markdown paragraph, where braces are
  just characters
- Escape them: `&#123;uid&#125;`
- Or pass the string as an expression: `{"users/{uid}/documents"}`

The same applies to `<` in prose — `<Thing>` inside a JSX chunk is parsed as a tag.
Backtick it, or keep it in markdown.

### 3. Fenced code and inline code are respected — mostly

The scanner skips over fenced blocks and inline code spans, so component examples inside
backticks stay as text rather than executing. A backtick run with no matching partner is
treated as literal text and does not swallow what follows.

## Frontmatter

YAML between `---` fences at the very top. Everything is optional.

```yaml
---
title: "Document title"
subtitle: "Optional subtitle"
description: "Longer summary paragraph"
author: "Name"            # or authors: ["A", "B"]
authorAvatar: "https://..."
date: "2026-08-06"
category: "Architecture"
status: "Draft"
tags: ["one", "two"]
readTime: "12 min read"
---
```

Any key you add that is not in that list renders as an extra field card at the bottom of
the header. Nested objects, arrays and dates are flattened to readable strings.

## Components

All of these are available in any document with no import.

### Layout and emphasis

```jsx
<Callout type="info" title="Heading">Body text.</Callout>
```
`type` — `info` · `note` · `warning` · `success` · `error`

```jsx
<CardGrid cols={2}>
  <Card title="Title" subtitle="Sub" icon="Eye" badge="New">Body.</Card>
</CardGrid>
```
`icon` takes any [lucide](https://lucide.dev/icons) name.

```jsx
<StatGrid cols={3}>
  <Stat title="Total Visitors" value="124,850" change="+18.4%" trend="up" icon="Users" />
</StatGrid>
```

```jsx
<Tabs labels={["One", "Two"]}>
  <Tab title="One"><p>First panel.</p></Tab>
  <Tab title="Two"><p>Second panel.</p></Tab>
</Tabs>

<Accordion items={[{ title: "Question?", content: "Answer." }]} />

<Timeline items={[{ date: "Q1 2026", title: "Milestone", description: "...", icon: "Rocket" }]} />

<Steps>
  <Step number={1} title="First">Do this.</Step>
</Steps>
```

> Inside a JSX chunk, markdown is **not** processed. Use `<p>`, `<strong>`, `<code>`
> and friends within component children, not `**bold**`.

### Inline

```jsx
<Badge>Label</Badge>  <Kbd>Ctrl</Kbd>  <InlineCode>value</InlineCode>
<ProgressBar progress={82} label="Deploying" color="emerald" />
<InteractiveCounter initial={42} min={0} max={100} step={5} title="Counter" />
```

### Diagrams

A fenced `mermaid` block, or the component:

```jsx
<Mermaid chart={`flowchart LR
    A["Start"] --> B["End"]`} />
```

Invalid diagram syntax renders an inline error card; it does not break the document.

### Charts

```jsx
<Chart
  type="area"
  title="Monthly growth"
  data={[{ name: 'Jan', value: 1200 }, { name: 'Feb', value: 1900 }]}
/>
```
`type` — `area` · `line` · `bar` · `pie`

### FlowGraph

An interactive architecture diagram: nodes, edges, and a flows panel that highlights a
complete path when selected. Hovering or keyboard-focusing a node shows its description.

```jsx
<FlowGraph
  title="Optional title"
  data={{
    groups: [{ id: "ui", label: "Components" }],
    nodes: [
      { id: "A", label: "Editor", group: "ui", kind: "ui", description: "Shown on hover." },
      { id: "B", label: "Store", kind: "store" }
    ],
    edges: [{ from: "A", to: "B", label: "writes" }],
    flows: [{ id: "save", label: "Save", summary: "What happens.", path: ["A", "B"] }]
  }}
/>
```

- `kind` — `ui` · `state` · `module` · `external` · `store` · `decision` · `risk`
- `groups` are horizontal bands, drawn top to bottom. Omit them and layers are derived
  from the edges.
- Edges also accept `"A->B"` or `["A", "B"]`.
- Below ~760px of container width, the flows panel stacks under the diagram.
- In PDF export it renders static, with all flows listed and their paths written out.

## Exporting

**Export → Export to PDF Document** produces A4 with page breaks that avoid splitting
diagrams, headings, tables and the frontmatter card. It runs entirely in the browser and
works on mobile.

<Callout type="warning" title="Two things to know about the PDF">
  The output is a raster image, so its text is not selectable or searchable. And the
  exporter strips every button element, so tab labels and accordion questions do not
  appear in the PDF — only the open panel's content does.
</Callout>
